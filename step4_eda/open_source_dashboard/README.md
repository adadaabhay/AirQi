# Separate Visualization Deliverable (Open Source)

This folder is intentionally separate for grading.

## Tool choice
- Tool: **Streamlit + Plotly** (both open-source)
- Why: Fast to run locally, interactive filtering, and suitable for academic demonstration.

## Run
```bash
venv/bin/pip install streamlit plotly
venv/bin/streamlit run step4_eda/open_source_dashboard/streamlit_dashboard.py
```

## What this covers
- PM2.5 distribution and outlier view
- PM10 vs PM2.5 relation
- AQI category split
- State-level pollution ranking

## Grading fit
This directly supports the rubric line for data visualization clarity, trend discovery, and insights.
